# Personal Expense Tracker with CSV

## Project Description

Personal Expense Tracker is a Python-based command-line application used to manage daily expenses. The project stores expense information in a CSV file for persistent data management.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Edit an existing expense
- Delete an expense
- Calculate total expenses by category
- Validate menu choices from 1 to 7
- Validate dates in DD-MM-YYYY format
- Accept only integer values for expense amounts
- Display error messages for invalid inputs
- Store expense data using CSV

## Technologies Used

- Python
- CSV
- datetime
- os

## Project Files

- `expense_tracker1.py` - Main Python program
- `expenses.csv` - Stores expense data
- `README.md` - Project documentation
